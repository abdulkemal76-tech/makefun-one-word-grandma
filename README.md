Entry for the make.fun bounty [One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16): a program that writes exactly one word to `/output/entry.txt` — the single word our grandma would text about AI.

## The word

**artifishal**

Grandma heard "artificial intelligence" on the news and tried to type the fancy word herself — and flubbed it into "artifishal". A typo she would actually make, literally half of "artificial intelligence", warm and a little baffled, with the fish pun landing the joke in one word and no caption.

## Run

```sh
python3 -P -s main.py
```

Writes `artifishal` (10 bytes, no trailing newline) to `/output/entry.txt`.
